# Hello C# MCP

This repo contains two sample "hello world" solutions
that use the C# MCP SDK.

The `Hello.Mcp` folder / solution shows the simplest
possible MCP server, which uses STDIO and would need
to be "installed" or put on the user's local machine
for them to be able to use it.

The `AspNetCoreMcp` folder / solution shows
an ASP.NET Core MCP server which would typically
be used for a remote (hosted) server that could
support multiple users without local installs for
those users.

See the readme's in those folders for more
information about each solution.
